# Member Onboarding

Welcome to ACLAB! This section gets new members up to speed in their first weeks.

## First steps

1. Read the [Lab Rules & Safety](/docs/lab-rules) guide.
2. Get access to the lab GitHub org and communication channels.
3. Set up your development environment (see your project's technical category).
4. Pick a starter task with your mentor.

## Checklist for new members

- [ ] Joined the ACLAB GitHub organization
- [ ] Added to the relevant project team / channel
- [ ] Read lab rules and safety guidelines
- [ ] Completed environment setup
- [ ] Met your mentor and chose a starter task
