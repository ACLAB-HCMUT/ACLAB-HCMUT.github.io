# Member Onboarding

Welcome to **ACLAB**! This guideline gets new members up to speed in their first weeks —
accounts, software to install (by skill domain), bench skills, and where to go next in the
Knowledge Base.

## First steps

1. Read the [Lab Rules & Safety](/docs/lab-rules) guide **before** using any equipment.
2. Join the ACLAB accounts & channels (below).
3. Install the software for your skill domain(s) (below).
4. Set up your project environment — see the matching technical category.
5. Meet your mentor and pick a starter task.

## Bench skills & lab tools

Beyond software, lab work needs hands-on hardware skills. **Get trained by a mentor and read
[Lab Rules & Safety](/docs/lab-rules) before using any of these.**

| Tool | Used for |
| --- | --- |
| **Soldering iron** | Through-hole & SMD soldering, rework |
| **Hot air station** | SMD components, reflow & desoldering |
| **Oscilloscope** | Observing signals, timing, debugging |
| **Multimeter** | Voltage/current/continuity, basic diagnostics |
| **Bench power supply** | Powering and current-limiting prototypes |
| **Logic analyzer** | Decoding digital buses (UART, I²C, SPI) |

→ How to use each instrument: [Lab Equipment Guides](/docs/equipment).
