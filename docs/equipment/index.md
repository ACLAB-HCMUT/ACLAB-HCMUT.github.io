# Lab Equipment Guides

How to safely and correctly use shared lab equipment.

## Equipment categories

- **Measurement:** oscilloscope, multimeter, logic analyzer, bench power supply
- **Rework:** soldering stations, hot-air, reflow
- **Fabrication:** 3D printers, CNC, hand tools
- **Compute:** edge-AI devices (Jetson), shared workstations/GPU

## Usage policy

- Book shared equipment before use.
- Log issues and consumable usage.
- Follow the [Lab Rules & Safety](/docs/lab-rules) guidelines.

> Add a per-device guide: setup, correct use, common mistakes, maintenance.
