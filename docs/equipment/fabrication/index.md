# Fabrication & Workshop Machines

Machines that **make and assemble** physical things — enclosures, mechanical parts, and
populated PCBs. These are shared, higher-value tools: book them, learn the safety rules, and ask
before first use.

## In this section

- [**3D Printing**](/docs/equipment/fabrication/3d-printing) — FDM and resin (SLA) printers.
- [**CNC & Laser**](/docs/equipment/fabrication/cnc-machining) — CNC mills/routers, lathes, laser cutters/engravers.
- [**PCB Assembly**](/docs/equipment/fabrication/pcb-assembly) — pick-and-place, reflow ovens, stencils.

:::danger Machine safety first
These machines have moving parts, heat, lasers and dust. Read [Lab Rules & Safety](/docs/lab-rules),
use eye/ear protection and extraction where required, and never leave a running machine
unattended.
:::

| Need | Machine |
