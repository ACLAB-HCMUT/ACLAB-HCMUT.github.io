# 9. Chuẩn bị Nghề nghiệp

Hãy chuẩn bị cho sự nghiệp song song với việc học — đừng đợi đến năm cuối. Để xem chi tiết
ánh xạ từ môn học sang các vị trí công việc, xem [Lộ trình Nghề nghiệp](/guide/career-paths).

## Hướng nghề nghiệp theo chuyên ngành

| Hướng đi | Các vị trí phổ biến |
| --- | --- |
| **AI** | ML Engineer, Data Scientist, AI Research |
| **Phần mềm** | Backend / Frontend / Full-stack, Mobile Dev |
| **Dữ liệu** | Data Engineer, Data Analyst, BI Engineer |
| **Bảo mật** | Security Engineer, Pentester, SOC Analyst |
| **Hệ thống** | Embedded/Systems Engineer, DevOps, HPC |

Chưa chắc về hướng đi? Xem [Chọn Hướng đi của Bạn](/guide/directions).

## CV kỹ thuật

- Một trang, tập trung vào **kỹ năng + dự án + kết quả đo lường được** (không chỉ là danh sách môn học).
- Với mỗi dự án: vấn đề → bạn đã làm gì → công nghệ → kết quả; kèm liên kết GitHub/demo.

## Portfolio trên GitHub

- Các repo gọn gàng với README rõ ràng (mục tiêu, cách chạy, ảnh chụp màn hình/demo).
- Lịch sử commit sạch sẽ; ghim (pin) 3–6 repo tốt nhất của bạn.

## LinkedIn

- Một dòng tiêu đề (headline) nêu rõ hướng đi của bạn; một mô tả ngắn về kỹ năng & dự án.
- Kết nối với bạn cùng lớp, mentor, cựu sinh viên và nhà tuyển dụng.

## Danh sách kiểm tra cho kỳ thực tập

- [ ] Hoàn thiện CV + GitHub + LinkedIn.
- [ ] 1–2 dự án có demo.
- [ ] Luyện DSA & kiến thức nền tảng cho phỏng vấn.
- [ ] Một danh sách các công ty/phòng lab mục tiêu + hạn nộp đơn.

## Kiến thức cơ bản về phỏng vấn kỹ thuật

- **DSA & giải quyết vấn đề** — luyện tập đều đặn trên LeetCode/Codeforces.
- **Kiến thức nền tảng** — hệ điều hành, mạng, cơ sở dữ liệu, tùy theo mô tả công việc.
- **Phỏng vấn hành vi (behavioral)** — kể câu chuyện dự án của bạn theo mô hình STAR (Tình huống–Nhiệm vụ–Hành động–Kết quả).
