# AI / Edge AI

Học máy (machine learning) và thị giác máy tính, tập trung vào việc triển khai mô hình trên thiết bị.

## Các chủ đề

- **Nền tảng:** pipeline huấn luyện, dataset, đánh giá
- **Thị giác máy tính:** phân loại, phát hiện (detection), phân vùng (segmentation)
- **Triển khai trên Edge:** Jetson, Raspberry Pi, vi điều khiển (TinyML)
- **Tối ưu hóa:** quantization, pruning, ONNX, TensorRT
- **Tích hợp:** kết nối mô hình với robot và hệ thống nhúng

## Bắt đầu

1. Thiết lập Python với NumPy và PyTorch (hoặc TensorFlow).
2. Huấn luyện một bộ phân loại nhỏ và export nó (ONNX).
3. Chạy suy luận (inference) trên thiết bị edge và đo độ trễ/công suất.

> Chia sẻ notebook và ghi chú triển khai tại đây.
