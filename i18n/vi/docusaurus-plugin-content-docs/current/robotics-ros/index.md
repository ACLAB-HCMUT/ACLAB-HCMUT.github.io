# Robotics & ROS

Xây dựng robot với ROS 2 — điều khiển, nhận thức (perception) và điều hướng.

## Các chủ đề

- **Kiến thức cơ bản về ROS 2:** node, topic, service, action, launch file
- **Chuyển động:** điều khiển động cơ, động học (kinematics), PID, điều khiển quỹ đạo
- **Nhận thức (Perception):** camera, LiDAR, IMU, hợp nhất cảm biến (sensor fusion)
- **Điều hướng:** odometry, SLAM, lập kế hoạch đường đi (Nav2)
- **Mô phỏng:** Gazebo, RViz

## Bắt đầu

1. Cài đặt ROS 2 (bản phân phối LTS) trong một môi trường sạch.
2. Build và chạy một node publisher/subscriber tối thiểu.
3. Khởi chạy một robot description và trực quan hóa nó trong RViz.

> Bổ sung các hướng dẫn thực hành theo cấu trúc hướng dẫn chuẩn.
