# CLAUDE.md — ACLAB HCMUT Website

Guidance for AI agents. Read first; follow across sessions. Keep this file concise and current.

## What
Public website for **ACLAB (Advanced Computing Lab), HCMUT**. **Docusaurus** (TS + React),
deployed to `https://aclab-hcmut.github.io` (GitHub Pages, org `ACLAB-HCMUT`). **English-only.**

## Commands
- `npm run start` — dev server · `npm run build` — prod build (`onBrokenLinks: 'throw'` → a
  broken internal link **fails the build**) · `npm run typecheck` (`tsc`) · `npm run serve`.
- Before finishing a change: run `typecheck`, and `build` if you touched links/docs/config.
- **Restart the dev server after editing `docusaurus.config.ts` / `sidebars*.ts` /
  `_category_.json`** — these don't hot-reload reliably and can leave routes (e.g. `/courses`)
  crashed in dev while `build` still passes. Fix: `npm run clear && npm run start`.
- **Deploy:** `.github/workflows/deploy.yml` auto-builds + deploys on push to `main`. Requires
  repo Settings → Pages → Source = "GitHub Actions". `/build` is gitignored.

## Structure — three docs instances + React pages
- **React pages** `src/pages/*.tsx`: index, about, research, projects, people, partners,
  contact, join.
- **Components & types** `src/components/index.tsx` (`Project`, `Member`, `Partner`, cards);
  CSS in `*.module.css`.
- **Data — edit these, not JSX** (`src/data/`): `projects.ts` (`featuredProjects = slice(0,3)`),
  `people.ts` (`peopleGroups`, `peopleHighlight`), `site.ts` (`partners`, `stats`),
  `research.ts` (a project's `area` must equal a research `title`).
- **Docs instances** (sidebars autogenerated from folders + `_category_.json`):
  - `docs/` → **Knowledge Base**, `routeBasePath: docs`, sidebar `knowledgeBase` (`sidebars.ts`).
  - `courses/` → **Courses**, id `courses`, `routeBasePath: courses` (`sidebarsCourses.ts`).
  - `guide/` → **BKU Student Guide**, id `guide`, `routeBasePath: guide` (`sidebarsGuide.ts`).
- **Config** `docusaurus.config.ts` (navbar/footer/plugins). Static assets `static/img/`
  (member photos in `static/img/people/`). `build/` is generated — never edit.

## Conventions
- **Bilingual (EN + VI) — ship both.** Every content page must exist in **English and
  Vietnamese**. Author the English source in `docs/`, `courses/`, `guide/`; put the Vietnamese
  version in the **mirrored i18n path** — never inline VI in the English source:
  - `docs/<p>` → `i18n/vi/docusaurus-plugin-content-docs/current/<p>`
  - `courses/<p>` → `i18n/vi/docusaurus-plugin-content-docs-courses/current/<p>`
  - `guide/<p>` → `i18n/vi/docusaurus-plugin-content-docs-guide/current/<p>`
  Translate only the `title:`; keep `slug`/`sidebar_position`/links/code blocks unchanged. **When
  you add or edit an English page, create/update its VI counterpart in the same change.** UI
  labels live in `i18n/vi/*.json`; React pages (`src/pages`) localize via `<Translate>` +
  `i18n/vi/code.json`. Keep proper names with diacritics (e.g. "Lê Trọng Nhân", "Bách Khoa").
  - Build builds **all locales**; preview VI in dev with `npm run start -- --locale vi`. **Commit `i18n/`.**
- **Concise & scannable.** Keep content short and easy to understand; prefer bullet points
  over long paragraphs. Break dense topics into small sections with clear headings; use
  tables/admonitions for structure. Don't pad — say it plainly, then stop.
- **Don't hardcode content in JSX** — edit `src/data/*`; pages map over it.
- **New docs page:** add the `.md` (+ `_category_.json` for a new folder), then `build` to
  check links. Cross-link with `[text](/path)`.
- **Course page:** plain English markdown — Overview → Objectives → Hardware/Tools →
  Exercises → Report/Submission → Resources.
- **Project card** optional `to` → its wiki (e.g. `/docs/projects/<slug>`); else `/projects#<slug>`.
- **Member card** optional `photo` (`/img/people/<file>`) else initials. Agents can't write
  images — wire the path and ask the user to drop the file in `static/img/people/`.
- **Verify names before relying on them** — paths/symbols here may drift.
