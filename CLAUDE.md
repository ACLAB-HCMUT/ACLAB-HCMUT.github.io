# CLAUDE.md — ACLAB HCMUT Website

Guidance for AI agents working in this repo. Read this first; follow it across sessions.

## What this is

The public website for **ACLAB (Advanced Computing Lab)**, Ho Chi Minh City University of
Technology (HCMUT). Built with **Docusaurus** (TypeScript + React) and deployed to
`https://aclab-hcmut.github.io` (GitHub Pages, org `ACLAB-HCMUT`).

## Commands

- `npm run start` — local dev server.
- `npm run build` — production build. `onBrokenLinks: 'throw'`, so a broken internal link
  **fails the build** — always build after touching links/slugs/nav.
- `npm run typecheck` — `tsc`. Run after editing any `.ts`/`.tsx`.
- `npm run serve` — serve the built site.

Before finishing a change, run `npm run typecheck` and (if links/docs/config changed)
`npm run build`.

**Restart the dev server after config/sidebar changes.** Editing `docusaurus.config.ts`,
`sidebars.ts`, `sidebarsCourses.ts`, or adding/changing a `_category_.json` is **not
reliably hot-reloaded** — the running `npm run start` can leave routes (e.g. `/courses`) in a
crashed/blank state even though `npm run build` passes. Fix: stop the dev server, then
`npm run clear && npm run start`. If a page "crashes" only in dev but builds fine, this is
almost always the cause. Note: there are **pre-existing broken-anchor warnings** on `/` and
`/projects` (research/projects `#anchor` links) — these are warnings, not errors; don't
treat them as something you broke.

## Structure & where content lives

- **Custom React pages:** `src/pages/` (`index.tsx`, `about.tsx`, `research.tsx`,
  `projects.tsx`, `people.tsx`, `partners.tsx`, `contact.tsx`, `join.tsx`).
- **Shared components & types:** `src/components/index.tsx` (e.g. `Project`, `Member`,
  `Partner`, cards). Styles in `src/components/ui.module.css`, `src/pages/*.module.css`.
- **Data (edit these, not the markup):**
  - `src/data/projects.ts` — projects (`Project[]`, `featuredProjects = slice(0,3)`).
  - `src/data/people.ts` — team (`peopleGroups`, `peopleHighlight`).
  - `src/data/partners` lives in `src/data/site.ts` (`partners: Partner[]`, `stats`).
  - `src/data/research.ts` — research areas (project `area` must match a `title` here).
- **Knowledge Base docs:** `docs/` (default docs instance, sidebar `knowledgeBase`,
  `routeBasePath: docs`, autogenerated from folders + `_category_.json`).
- **Courses docs:** `courses/` (separate `@docusaurus/plugin-content-docs` instance,
  id `courses`, sidebar `courses`, `routeBasePath: courses`, sidebar file
  `sidebarsCourses.ts`).
- **Student Guide docs:** `guide/` (separate docs instance, id `guide`, sidebar `guide`,
  `routeBasePath: guide`, sidebar file `sidebarsGuide.ts`). The "BKU Student Guide" — a
  practical guide for HCMUT CS students (11 sections, navbar tab "Student Guide"), in English.
- **Config:** `docusaurus.config.ts` (navbar/footer/plugins), `sidebars.ts`,
  `sidebarsCourses.ts`. Static assets in `static/img/` (member photos in
  `static/img/people/`).
- `build/` is generated output — never edit by hand.

## Conventions / rules

- **Don't hardcode content in JSX** — add/edit entries in the `src/data/*` files; the pages
  map over them.
- **The whole site is English-only.** All content (Knowledge Base, Courses, Student Guide,
  pages) is in English. Do not add Vietnamese body text. The only Vietnamese allowed is
  **proper names** with diacritics (e.g. "Lê Trọng Nhân", "Trần Ngọc Cát", "Bách Khoa") —
  keep those as-is. (History note: Courses were briefly bilingual via a `<Tabs groupId="lang">`
  toggle; that was removed when the site went English-only. If bilingual is ever reintroduced,
  that Tabs pattern is the approach.)
- **Course page structure:** plain English markdown, sections Overview → Objectives →
  Hardware/Tools → Exercises → Report/Submission → Resources.
- **Project cards** support an optional `to` field — use it to link a card to its wiki page
  (e.g. `/docs/projects/<slug>`); otherwise it falls back to `/projects#<slug>`.
- **Member cards** support an optional `photo` field (`/img/people/<file>`); falls back to
  initials. Agents can't write binary images — when a photo is needed, wire the path and ask
  the user to drop the file in `static/img/people/`.
- Adding a new docs page: create the `.md` (+ `_category_.json` for a new folder), then build
  to confirm no broken links. Cross-link with markdown `[text](/path)` (relative from root).
- **Verify before recommending:** file/symbol names in this doc may drift — confirm they
  still exist before relying on them.
