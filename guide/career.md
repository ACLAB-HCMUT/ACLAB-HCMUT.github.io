# 9. Career Preparation

Prepare for your career alongside your studies — don't wait until the final year. For a
detailed mapping of courses to roles, see [Career Paths](/guide/career-paths).

## Career directions by specialization

| Direction | Common roles |
| --- | --- |
| **AI** | ML Engineer, Data Scientist, AI Research |
| **Software** | Backend / Frontend / Full-stack, Mobile Dev |
| **Data** | Data Engineer, Data Analyst, BI Engineer |
| **Security** | Security Engineer, Pentester, SOC Analyst |
| **Systems** | Embedded/Systems Engineer, DevOps, HPC |

Not sure which direction? See [Choose Your Direction](/guide/directions).

## Technical CV

- One page, focused on **skills + projects + measurable results** (not just a course list).
- For each project: problem → what you did → technologies → result; include GitHub/demo links.

## GitHub portfolio

- Tidy repos with clear READMEs (goal, how to run, screenshots/demo).
- Clean commit history; pin your 3–6 best repos.

## LinkedIn

- A headline that states your direction; a short description of your skills & projects.
- Connect with classmates, mentors, alumni and recruiters.

## Internship checklist

- [ ] Complete CV + GitHub + LinkedIn.
- [ ] 1–2 projects with a demo.
- [ ] Practice DSA & fundamentals for interviews.
- [ ] A list of target companies/labs + application deadlines.

## Technical interview basics

- **DSA & problem solving** — practice regularly on LeetCode/Codeforces.
- **Fundamentals** — operating systems, networks, databases, per the job description.
- **Behavioral** — tell your project story with the STAR model (Situation–Task–Action–Result).
