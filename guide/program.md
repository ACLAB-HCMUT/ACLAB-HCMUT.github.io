# 2. Understand the Program

An overview of a typical Computer Science curriculum — general orientation only. Your actual
credits, course codes and prerequisites depend on your own program and cohort.

## Total credits and course groups

The program is divided into course groups (knowledge blocks):

- **General education** — math, basic sciences, politics, foreign languages.
- **Core foundations** — programming and computer-systems fundamentals.
- **Specialization** — core courses and direction-specific courses.
- **Electives** — chosen according to your career direction.
- **Internship & projects** — internship, specialized project, graduation thesis.

> Total credits and the exact breakdown: check **your cohort's official program** (each cohort
> can differ). Don't rely on memory — always cross-check the official document.

## Program map

A typical path from foundations → specialization → graduation:

```
Foundations (Y1)  →  Core systems & DSA (Y2)  →  Specialization (Y3)
        →  Internship + specialized project (Y3–Y4)  →  Graduation thesis (Y4+)
```

Detail by knowledge block: see [Course Map](/guide/course-map).
Detail by year: see [Semester-by-Semester Guide](/guide/semester-guide).

## Key milestones

- **Foundation courses** — math, intro to programming, discrete structures.
- **Core courses** — DSA, OOP, computer architecture, operating systems, databases, networks.
- **Specialization courses** — by direction (AI / Software / Data / Security / Systems).
- **Electives** — reinforce your chosen direction.
- **Internship** — real-world work at a company or lab.
- **Specialized project** — a large project in your chosen direction.
- **Graduation thesis** — a complete product/research work (see an example in
  [Projects](/docs/projects/vr-robot-arm-teleoperation)).

## Symbols explained

- **Prerequisite:** you must finish course A **before** taking course B.
- **Corequisite:** take A **in the same term** as B.
- **Recommended:** a background is advisable, but not mandatory.
- **Required:** a course that cannot be substituted.
- **Elective:** chosen from a list to meet the required number of credits.

> Registering courses in the wrong prerequisite order is a common mistake — see the
> [Student Survival Guide](/guide/survival-guide#course-registration).
