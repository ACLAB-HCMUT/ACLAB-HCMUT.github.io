# 4. Choose Your Direction

This page helps you pick a direction **early** without being "locked in". You can change
direction — the foundations (math + programming + systems) are shared across all directions.
Pick one primary direction to build a portfolio, while still learning broadly.

## Artificial Intelligence

- **Related courses:** Introduction to AI, Programming for AI & Data Science, Machine Learning,
  Deep Learning, NLP, Computer Vision.
- **Skills:** Python, NumPy, PyTorch, data processing, Linux, Git.
- **Project ideas:** image classifier, chatbot, OCR, vision robot.

→ Related to the [IoT + edge AI work in Courses](/courses/iot) and the lab's research.

## Software Engineering

- **Related courses:** Software Engineering, Testing, Architecture, Web Programming, Mobile.
- **Skills:** Git, backend, frontend, database, Docker, CI/CD.
- **Project ideas:** web app, SaaS mini-product, mobile application.

## Data Engineering & Big Data

- **Related courses:** DBMS, Data Mining, Data Warehouse, Big Data, BI.
- **Skills:** SQL, Python, ETL, cloud, data pipeline.
- **Project ideas:** dashboard, data warehouse, analytics pipeline.

## System & Network Security

- **Related courses:** Network Management, Cryptography, Security Assessment, Information
  System Security.
- **Skills:** Linux, networking, scripting, security fundamentals.
- **Project ideas:** home lab, network monitor, CTF write-up.

## Computer Science / Systems

- **Related courses:** Parallel Computing, Computer Graphics, IoT, Mobile, HPC.
- **Skills:** C/C++, Linux, systems design, algorithms.
- **Project ideas:** compiler mini-project, graphics demo, IoT platform.
