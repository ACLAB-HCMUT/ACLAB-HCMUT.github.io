## AI coding assistants

AI coding assistants (Copilot, Claude, ChatGPT, Cursor…) **speed you up** but **don't replace**
understanding.

- **Good uses:** explain errors, suggest structure, write tests, learn new syntax, quick review.
- **Limitations:** they can be wrong or "hallucinate"; you must **verify** and understand the
  code you submit.
- **Academic note:** follow each course's rules on AI use; many courses require you to write
  your own code.
